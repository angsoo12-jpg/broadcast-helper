1. 골든 룰 (조작 대전제)
  1. SELECT 우선: EQ·컴프·게인 등 모든 조작 전, 반드시 해당 채널 SELECT를 먼저 누릅니다.
  2. 육안 확인: 누른 뒤 콘솔 중앙 화면 상단에 채널 이름·번호가 맞게 떴는지 확인합니다.
  3. 사고 사례: SELECT가 이전 채널에 머문 채 노브를 돌리면, 현재 소리 나는 목사님/찬양팀 채널이 변질·끊기는 사고가 납니다.

입력(In) / 출력(Out) 구분

  • 왼쪽(인풋): 마이크·신디·통기타·PC 등 들어오는 채널 (1~16, 17~32, Aux In).
  • 오른쪽(아웃풋): 스피커·모니터·OBS 등 나가는 채널 (DCA, Group, Bus Master, Main LR).
2. 비상 복구 및 신(Scene) 관리

2.1 Scene 저장 / 불러오기

  • 저장: SHOW CONTROL → SAVE로 현재 설정을 신(Scene)으로 저장.
  • 불러오기(복구): SHOW CONTROL → 승인된 최신 날짜 신 선택 → GO → Confirm(YES).

2.2 Assign A5 — 원클릭 비상 복구

  • 세팅: ASSIGN → VIEW → Set A → Button 5(A5)에 '최신 Scene Recall' 할당.
  • 사용: 소리 꼬임 시 A5 → 화면 Confirm(YES)(또는 엔코더 버튼) → 즉시 정상 복구.

2.3 USB 전체 백업

SETUP → Global → Backup Export로 콘솔 전체 데이터를 USB에 저장. 초기화 시 Restore로 복원. 큰 튜닝 변경마다 수행.

3. 마이크·악기 정밀 톤 (PEQ & RTA)

3.1 RTA로 하울링/피드백 제거

  1. 채널 SELECT → EQ VIEW → RTA 활성화.
  2. 입력 시 붉게 솟는 피드백 주파수를 찾습니다.
  3. Gain을 -5~-6dB 깎고, Q(폭) 노브로 인접 주파수 간섭을 최소화하며 정밀 튜닝.
  4. 보통 2~3개 포인트만 정돈해도 매우 명료해집니다.

3.2 신디사이저 원음 유지

  • Low Cut은 반드시 0Hz(끄기). 켜면 왼손 저음역대가 사라져 소리가 빈약해집니다.
  • EQ는 Reset(Flat) 유지 — 저음 깎고 고음 올리면 원음이 변질됩니다.

3.3 로우컷 예외 (마이크 한정)

컬럼 어레이 스피커 특성상 저음 울림이 강하거나 'ㅍ/ㅌ' 발음의 팝핑이 심할 때만, 예외적으로 마이크 채널 로우컷을 활성화합니다. (신디 등 악기 금지)

4. 다이내믹스 & 이펙터 (Comp & FX)

4.1 컴프레서

  • Threshold: GR(빨간 불)이 -3~-6dB(1~2칸) 살짝 걸리게.
  • Ratio: 1:3 유지.
  • Makeup Gain: 목사님·메인 리더 마이크에만 적용해 답답함을 줄이고 딕션을 자연스럽게 끌어올림 (코러스 0dB).

4.2 이펙터(FX) 확인 및 정돈

  • 현재 이펙터 확인: EFFECTS → HOME 탭에서 적용된 이펙터 종류 확인.
  • 배정: FX1=Hall(통기타·어쿠스틱), FX2=Plate(보컬·선명도).
  • 웅웅거림 제거: FX Return 채널 EQ에서 High/Low 대역을 Cut 해 지저분한 잔향 정돈.
  • FX Return Mute는 해제(켜짐) 유지해야 이펙터 소리가 들립니다.

4.3 Key Source — 딕션(가사 전달력) 확보 · 덕킹

원리: 발음이 세게 들어올 때 리버브 양이 자동으로 줄어 가사가 묻히지 않게 합니다.

  1. 보컬 채널들을 Bus 9로 전송하고, 해당 채널의 Main LR 출력을 끕니다 (Bus 9로만 전송).
  2. 이펙터 컴프레서의 Key Source를 Bus 9로 지정.
  3. 발음이 강할 때 GR이 -10dB 정도 작동하도록 세팅 → 딕션 극대화.
5. OBS 방송 송출 & 라우팅

5.1 Sends on Fader 역방향 조절 (추천)

  1. 출력 버스(Bus 9/10 · OBS용)를 SELECT.
  2. Sends on Fader를 누릅니다. 이때 페이더가 해당 버스 색상으로 변하는지 시각적으로 확인.
  3. OBS로 나가는 각 인풋 레벨을 한눈에 보며 밸런싱.
  4. 조절 완료 후 반드시 Sends on Fader 해제.

5.2 USB / OBS 라우팅

  1. PC에 M32/X32 전용 USB 드라이버 설치.
  2. ROUTING → Input Aux → Card 1-2 (PC 음악 수신).
  3. ROUTING → Card Out → User Out 선택 → User Out 탭에서 Mode를 'Out'으로 변경 후 Bus 9/10 할당.
  4. OBS '오디오 입력 캡처' 추가 → MIDAS/X32 USB Driver 선택.
  5. 게이지가 -20~-18dB(노란색 상단) 찰랑거리게 밸런싱.
  6. OBS는 5~10초 지연 → 조절 후 최소 10초 대기. 성급한 재조정은 믹스를 망칩니다.
  7. OBS 자체 필터 남용 금지 — 콘솔에서 충분한 원음 레벨을 확보한 뒤 송출.

5.3 모니터 출력 (Bus 1 / Bus 2)

Bus 1=목사님 모니터, Bus 2=찬양팀 모니터. Sends on Fader로 조절해 현장(메인) 스피커와 독립된 개별 볼륨 유지.

6. 그룹 제어 & 원격

6.1 DCA / Mute Group

  • Mute Group(1~6): 예배 전후 여러 마이크를 방송 사고 위험 없이 일괄 음소거.
  • DCA 절대 금지: DCA 페이더가 내려가거나 뮤트되면 채널 페이더를 올려도 무음. 보이지 않는 곳에서 제어돼 원인 불명 음소거 사고를 일으키는 주범이며, 초보자에겐 특히 위험합니다.

6.2 Mixing Station 앱 (스마트폰/태블릿)

  1. 콘솔 전용 와이파이(고정 IP)에 연결 → 앱 실행 → Add Mixer → X32/M32 Search → IP 선택 → Connect.
  2. 앱 내 [Enable] 버튼을 눌러야 뮤트 등 실시간 조작이 반영됩니다. (안 눌리면 조작해도 무반응)
  3. 사용자 레이어 편집: 목사님 마이크·신디·OBS 버스·메인 LR 등 자주 쓰는 채널만 배치.
7. 트러블슈팅

Q1. 소리가 전혀 안 난다

① 채널 SELECT+화면 확인 ② Mute / Mute Group ③ DCA 페이더·뮤트(초보 금지) ④ Sends on Fader 해제 ⑤ Mixing Station 앱이면 [Enable] 눌렀는지 확인.

Q2. '삐-' 하울링/피드백

EQ의 RTA로 솟구치는 주파수를 찾아 -5~-6dB 컷. Q 노브로 인접 간섭 최소화.

Q3. 퍽퍽 팝핑 / 저음 울림

컬럼 스피커 특성·입바람이 원인. 해당 마이크 채널에 예외적으로 Low Cut 활성화.

Q4. 신디 저음이 안 들린다

Low Cut을 즉시 해제(0Hz)하고 EQ를 Reset(Flat)으로.

Q5. OBS 소리가 작거나 뭉개진다

Sends on Fader 역방향으로 Bus 9/10 인풋 레벨 확보(게이지 -20~-18dB), OBS 소프트웨어 필터 제거.

Q6. USB '징-' 전기 노이즈

USB 직결의 접지 루프(Ground Loop). 직접 연결하지 말고 외부 오디오 인터페이스 경유.

Q7. 찬양 가사/딕션이 뭉개진다

리버브에 가사가 묻히는 경우. Bus 9 Key Source 컴프레서가 작동해 GR -10dB가 걸리는지 확인.

Q8. 통제 불능 긴급 상황

Assign A5 → 화면 Confirm(YES)(또는 엔코더 버튼)으로 신 리콜 완료.

8. 예배 시작 전 최종 확인
  • ☐ 조작 전 SELECT 버튼 및 화면 채널 이름 확인
  • ☐ 신디 Low Cut 해제(0Hz) 및 EQ Flat
  • ☐ OBS 레벨 -20~-18dB 찰랑
  • ☐ FX Return 채널 Mute 해제 상태
  • ☐ Assign A5 정상 작동
  • ☐ 불필요한 DCA 페이더가 내려가 있지 않은지
9. 운영 마감 체크리스트 (예배 종료 후)
  1. 최종 씬 저장(Save): 당일 최적 설정을 가장 먼저 저장.
  2. 뮤트 그룹 활성화: 모든 인풋 채널 일괄 음소거.
  3. 페이더 하향: 모든 메인·버스 페이더를 최하단으로.
  4. 전원 종료: 콘솔 뒷면 물리 스위치를 OFF.
